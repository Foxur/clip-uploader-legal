Privacy Policy

Foxur Clip Uploader · Last updated: 18 November 2026

1. Who uses the App

Foxur Clip Uploader is a private, single-user tool. It is only used by its developer with the developer's own TikTok accounts. No other users' data is processed.

2. Data processed

  • Basic TikTok profile information (open ID, display name, avatar) via the user.info.basic scope, used only to identify which of the owner's accounts is connected.
  • OAuth access and refresh tokens, used only to upload drafts via the video.upload scope.
  • Video files and captions created by the owner, sent to TikTok for upload.

3. Storage

Tokens and video files are stored only locally on the owner's own device. Nothing is stored on third-party servers other than TikTok itself.

4. Sharing

No data is sold, shared with or transferred to third parties, apart from the uploads to TikTok that the owner initiates.

5. Retention and deletion

Tokens are deleted when access is revoked or the App is no longer used. Access can be revoked at any time in the TikTok app under Settings → Security → Manage app permissions.

6. Contact

Questions: please open an issue in the GitHub repository hosting this page.
